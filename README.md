# Drivers Performance Dashboard

نظام متكامل لإدارة وتحليل أداء السائقين مع مزامنة سحابية، تقارير يومية، إدارة المركبات، والأهداف.

---

## ✨ المميزات الرئيسية

- 🏠 **لوحة تحكم ذكية** — مؤشر أداء عام، KPIs، رسوم بيانية تفاعلية
- 📅 **تقارير يومية** — إدخال فردي أو جماعي (يوم كامل بضغطة واحدة)
- 🚗 **إدارة السائقين** — مع نظام تقييم A-F تلقائي
- 👔 **إدارة المشرفين** — مع صلاحيات قابلة للتخصيص لكل مشرف
- 🚙 **إدارة المركبات** — سيارات، مكاتب تأجير، صيانة، أعطال، تغيير زيت
- 📈 **تحليلات متقدمة** — 8 أنواع تصفية (يوم/أسبوع/شهر/نطاقات مخصصة)
- 🎯 **نظام أهداف** — يومي، أسبوعي، شهري (عام + لكل مشرف)
- ☁️ **مزامنة سحابية** — عبر jsonbin.io مع دمج تلقائي للبيانات
- 🔔 **إشعارات فورية** — لكل إجراء مهم في النظام
- 🌐 **ثنائي اللغة** — عربي / إنجليزي
- 🔒 **صلاحيات وأمان** — مالك + مشرفين مع صلاحيات دقيقة
- ⏱️ **خروج تلقائي** بعد 30 دقيقة من عدم النشاط
- 💬 **تكامل واتساب** — للتواصل السريع
- 📱 **متجاوب بالكامل** — يعمل على الجوال والتابلت والحاسب

## 🚀 التشغيل السريع

### الطريقة 1 — فتح مباشر (بدون GitHub)
1. حمّل ملف `index.html`
2. افتحه في متصفحك مباشرة
3. سجّل دخول بحساب المالك
