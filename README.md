# 📊 لوحة تحليل أداء السائقين

نظام متكامل لإدارة ومتابعة أداء السائقين مع مزامنة سحابية عبر [jsonbin.io](https://jsonbin.io).

## ✨ المميزات

- 📅 تقارير يومية (يدوية + استيراد من Excel/PDF)
- 🚗 إدارة السائقين والمشرفين والمركبات
- 🎯 أهداف يومية/أسبوعية/شهرية
- 📈 رسوم بيانية تفاعلية (أعمدة، خطي، دائري)
- ⭐ نظام تقييم A–F للسائقين والأيام
- ☁️ مزامنة سحابية (تلقائية أو يدوية)
- 🌐 دعم العربية والإنجليزية (RTL/LTR)
- 📱 تصميم متجاوب للجوال
- 🖨️ طباعة التقارير

## 🚀 التشغيل المحلي

لا يحتاج تثبيت أي شيء — افتح `index.html` مباشرة في المتصفح.

## 🔐 بيانات الدخول الافتراضية

| الحقل | القيمة |
|-------|--------|
| البريد | `admin@drivers.local` |
| كلمة المرور | `ChangeMe@2026` |

> ⚠️ **غيّر كلمة المرور فوراً** من: الإعدادات ← تغيير كلمة المرور

## ☁️ إعداد المزامنة السحابية

1. أنشئ حساباً مجانياً على [jsonbin.io](https://jsonbin.io)
2. أنشئ **Bin** جديد (JSON)
3. انسخ **Master Key** و **Bin ID**
4. من التطبيق: الإعدادات ← ☁️ مزامنة jsonbin.io
5. الصق المفاتيح واحفظ
