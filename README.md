## ☁️ إعداد المزامنة السحابية
1. أنشئ حساباً على [jsonbin.io](https://jsonbin.io) (مجاني).
2. أنشئ **Bin** جديد.
3. انسخ **Master Key** و **Bin ID**.
4. اذهب إلى: الإعدادات ← مزامنة jsonbin.io.
5. الصق المفتاح و Bin ID واضغط "اختبار الاتصال".
6. اضغط "نسخ رابط المشاركة" لمشاركة البيانات مع الفريق.

## 🚀 النشر على GitHub Pages
1. ارفع الملفات إلى مستودع جديد.
2. اذهب إلى **Settings → Pages**.
3. اختر **Source: Deploy from a branch** → **Branch: main / (root)**.
4. انتظر دقيقة، ثم افتح الرابط.
