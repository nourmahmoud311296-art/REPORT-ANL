# 📊 لوحة تحليل أداء السائقين

نظام متكامل لمتابعة أداء السائقين مع مزامنة سحابية ومشاركة عبر رابط.

## 🌐 العرض المباشر (Demo)

بعد تفعيل GitHub Pages، الرابط سيكون:
`https://YOUR-USERNAME.github.io/YOUR-REPO/`

## ✨ المميزات

- 📊 لوحة تحكم بمؤشرات KPI ورسوم بيانية تفاعلية
- 📅 تقارير يومية مع مقارنة يومين
- 🚗 إدارة السائقين والمركبات والمشرفين
- 🎯 أهداف شهرية وأسبوعية مع مؤشر تحقيق تلقائي
- ⭐ نظام تقييم تلقائي (A–F) قابل للتخصيص
- ☁️ مزامنة سحابية عبر jsonbin.io
- 🔗 مشاركة الرابط بين الأجهزة بدون سيرفر
- 🌐 واجهة عربية/إنجليزية (RTL/LTR)
- 🎨 تخصيص الألوان والشعار وحجم الخط
- 📤 استيراد/تصدير البيانات JSON
- 🔔 نظام إشعارات داخلي
- 💬 زر تواصل واتساب مباشر
- 📱 متجاوب بالكامل مع الجوال

## 🚀 خطوات النشر على GitHub Pages

### 1) إنشاء المستودع
- اذهب إلى [github.com/new](https://github.com/new)
- اسم المستودع مثلاً: `drivers-performance`
- اختر **Public** ثم **Create repository**

### 2) رفع الملفات

**الطريقة الأولى — عبر Git:**
```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/drivers-performance.git
git push -u origin main
